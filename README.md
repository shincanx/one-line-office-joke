A deterministic Python program that writes one line of office humour — at most 200 characters, about the weekly sync that should have been an email — to /output/entry.txt. The joke: the meeting's only real product is an audience for my nodding at slides I stopped reading in 2021.

## Run it

```sh
python3 main.py
```
